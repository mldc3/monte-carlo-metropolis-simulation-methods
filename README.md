# Monte Carlo & Metropolis Simulation Methods

A clean scientific-computing portfolio repository for final-year computational physics work focused on Monte Carlo integration, Metropolis sampling, numerical validation, and scientific Python workflows.

## Project Overview

This repository is structured to host:

- Python simulation scripts and reusable source modules
- Theory notes and method derivations
- Generated figures and plots
- Analysis of numerical results and validation checks
- Original course scripts and reports for reference

## Installation

1. Clone the repository.
2. (Recommended) create and activate a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

## How to Run

This project is scaffolded and ready for your scripts.

- Place executable simulation code inside `src/`.
- Run scripts directly, for example:

```bash
python src/your_simulation_script.py
```

## Repository Structure

- `src/` – Python source code for simulations
- `docs/` – theory notes and result analysis
- `figures/` – generated plots and visual outputs
- `raw/` – original course scripts and reports
